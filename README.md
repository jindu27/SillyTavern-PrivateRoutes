# 多线群聊 · Private Routes

给 SillyTavern 1.19.0 的群聊加入 AI 主卡和独立剧情。你只和主卡互动。主卡可以在同一轮内联系多张副卡，每张副卡都只根据自己的角色设定及与主卡的经历生成回应。

## 安装

1. 启动 SillyTavern，连接可用的模型。
2. 打开顶部的「扩展」→「安装扩展」，粘贴：

       https://github.com/jindu27/SillyTavern-PrivateRoutes

3. 安装完成后刷新页面。打开一个由多张角色卡组成的群聊，在输入框上方勾选「多线群聊」，再从下拉框选择主卡。
4. 照常在酒馆输入框发消息。扩展开关和主卡按群聊保存，每个聊天存档单独记录剧情。

这是一个前端扩展。模型生成复用酒馆当前的连接，适合能稳定输出 JSON 的模型。连接的生成长度需要足够容纳一轮分段回复。扩展使用自己的对话编排和上下文，角色卡文本会参与生成，原生群聊的历史和世界书注入不参与分线。

## 一轮怎么进行

- 主卡可以对玩家和多张副卡分别行动。输出按对象分块，无动作显示「主卡本轮无行为」。
- 被主卡联系的副卡必须回应。其余副卡可以自己发消息或跳过。主卡根据剧情决定立即接话几次，或等下一条玩家消息。输入框右侧的停止按钮可以取消正在生成的整轮并保留输入。生成期间会在聊天底部逐段显示已经完成的 `@` 区块，整轮保存后再替换为正式消息。
- 约定见面仍属于线上。剧情确实见面时进入线下约会，可以持续多轮。其他人可在剧情经过的时间里独立发消息，按各自的分线保存，主卡约会结束后在同一轮按对象补回。
- 剧情时间从第 1 天开始，随叙事推进。例如「吃完饭已经九点了」可以推动其他角色在这段时间里行动。页面打开或关闭的实际时长不推进剧情。

界面上你能看到所有分线。每次向副卡请求生成时，只提供它的角色卡、主卡名称、这一条线的近期历史和提供给它的行为。玩家的话和其他分线的内容不会自动并入。主卡可以在剧情中主动转述。其他会修改所有模型请求的扩展可能改变这项行为。

如果主卡包含 `【团子状态】` 规则，扩展会把好感度和执念保存到当前群聊的状态中，并在一轮回复的底部显示一次状态栏。状态栏使用当前群成员名称，兼容旧的 `aff_zhouye` 变量名。这里的流式显示按分线完成顺序更新，模型请求仍然以结构化小步骤生成。

格式校验失败会重试一次。模型失败或本轮停止时，可重新发送留在输入框里的消息。分线和待回复状态保存在对应的群聊存档，生成时会按上下文长度使用近期记录。当前仅处理文本。
